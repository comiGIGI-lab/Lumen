## 一、设计思路：别做成"功能罗列"，做成一条闭环

**错误做法**：从左到右点一遍导航，逐个说"这是知识库、这是错题本……"
→ 评委 30 秒后就开始走神，最后记住的是"功能挺多"，而不是**"这东西解决了什么问题"**。

**正确做法**：设一个**主角 + 一个目标**，所有功能都在解决问题的路上自然出现。

**本片主线（就一句话）**：
> 一个学生想自学《机器学习》，从"不知道从哪开始"到"学完、会复习、能自查"的全过程。

功能按"遇到什么问题 → 用了什么"的顺序出场，顺手全部走完：

```
想学但没方向   → 学习方案生成（大纲 / 资源 / 计划 + 导出 Word）
教材太厚找不到重点 → 文档导入 → 知识库（PDF 喂进去，变成可检索的材料）
学的时候有疑问   → 课程问答（基于自己的材料回答，还能把表格复制出去）
做作业做错了     → 错题本（记下来，形成自己的薄弱点清单）
怕自己半途而废   → 学习进度打卡 + 自习空间计时
复习时想通盘看   → 思维导图 + 历史 + 日志
（穿插）换个心情学 → 深色模式 / English
（最后）安全兜底  → 内容安全 + 危机干预
```

## 三、逐镜脚本

### 幕一 · 开场（0:00–0:20）

| 项 | 内容 |

**要拍到的**：顶部导航一字排开 `学习方案生成 / 知识库 / 文档导入 / 录音转写 / 课程问答 / 错题本 / 自习空间 / 更多`。

### 幕二 · 从 0 生成学习方案（0:20–1:50，本片最长，定调）

| 镜号 | 时长 | 操作 | 逐字稿（可直接念） |
|---|---|---|---|
| 2-1 | 15s | 在输入框打 `机器学习`（占位提示：*例如：机器学习、计算机网络、线性代数…*），把「学习目标 / 截止日期」也填一下 | "它先要的**不是问题，是条件**：你想学什么、每天几小时、什么时候要学完。" |
| 2-2 | 30s | 点 **✨ 生成方案**，**不要剪辑**，完整拍步骤条 | "注意这里 —— 这不是一次模型调用。**四个 Agent 在接力**：Planner 拆章节、Searcher 找资源、Writer 排计划、Reviewer 挑毛病。谁能看到中间过程，谁就知道它不是套壳。" |
| 2-3 | 25s | 结果出来后缓慢滚三栏：**课程大纲 / 推荐资源 / 学习计划** | "大纲是**章节 + 每章要点**，资源是可直接点的书和课，计划切到**每天该干什么**。" |
| 2-4 | 15s | 点大纲里的勾选框勾掉一章；再点 **复制大纲 / 复制计划** | "学过一章就勾一章，进度是**按天记的**，勾错会回滚。" |
| 2-5 | 15s | 滚到底部，点导出卡片里的 **导出方案** → 直接下 Word | "这份方案可以带走：**一键导出 Word 或 Markdown**，学生打印出来贴在桌上都行。" |

**要拍到的**：步骤条从灰变绿的过程；三栏里每章下面带要点的样子；导出下来的 Word 文件名。
**坑**：步骤条是**真在跑**（约 10 秒），别用加速播放，评委要看的就是这段"慢"。

### 幕三 · 把材料喂进去再提问（1:50–3:05）

| 镜号 | 时长 | 操作 | 逐字稿 |
|---|---|---|---|
| 3-1 | 20s | 点导航 **文档导入**，拖一个 PDF（课件/教材截图都行）进去 | "教材太厚，学生真正需要的是**从自己的材料里找答案**。所以第二步：把课件喂进去。" |
| 3-2 | 15s | 切到 **知识库**，展示刚导入的内容已经变成可检索的条目 | "导入不是存文件，是**切成片段、抽关键句**，成为可检索的知识库。" |
| 3-3 | 30s | 点 **课程问答**，问一个**材料里确实有**的问题，例如：`梯度下降的步长怎么选？` | "现在提问就**不一样了** —— 它先去你的知识库里检索，命中了才基于**你的材料**回答，而不是背一段通用答案。" |
| 3-4 | 20s | 追问一句让模型输出表格：`用表格对比一下批量梯度下降和随机梯度下降` | "回答是**真渲染的 Markdown**：标题、列表、表格、代码块都能读。" |
| 3-5 | 15s | 鼠标停在表格卡片右上角，点 **复制**（或下载 CSV） | "表格可以直接**复制进 Excel 或下载成 CSV** —— 这是学生真正会用到的动作。" |

**要拍到的**：问答气泡里「来源：知识库」这个标签（证明走了 RAG，不是纯聊天）。
**坑**：问题必须选**材料里真的有**的，命中失败会显示「大模型」，说服力掉一半。

### 幕四 · 学完之后的闭环（3:05–4:15）

| 镜号 | 时长 | 操作 | 逐字稿 |
|---|---|---|---|
| 4-1 | 25s | 点 **错题本**，加一条错题（题目 + 正确答案 + 错因） | "做题做错了要留下东西。错题本记录的不是题，是**这个人反复错的地方**。" |
| 4-2 | 20s | 点 **更多 → 思维导图**，展示节点可拖动/新增 | "学完一科要把结构画出来。思维导图**可以编辑**，不是只读的图片。" |
| 4-3 | 20s | 点 **更多 → 学习进度**，展示这门课的完成度 | "所有勾选都汇总到学习进度 —— **一周下来有没有坚持，这里看得见**。" |
| 4-4 | 15s | 点 **自习空间**，点「开始」让计时跑起来 | "真想学的时候开计时器，25 分钟一段。" |
| 4-5 | 15s | 点 **更多 → 深色模式**，界面切深色；再点 **English** 切英文 | "晚上学不刺眼；给留学生或做英文材料的同学，界面可以整个换语言。" |

**坑**（重要）：
- **深色模式切换后，记得切回浅色**再录下一幕（危机镜头用浅色更好看）。
- **English 切完也要切回中文**，否则后面导航全变英文，观众看不懂。
- 思维导图/进度那两页**数据要提前造好**（空页面拍出来很难看）：录之前先给《机器学习》勾几天进度、加 2 条错题。

### 幕五 · 安全底线（4:15–5:00）★ 本片最硬的一段

| 镜号 | 时长 | 操作 | 逐字稿 |
|---|---|---|---|
| 5-1 | 20s | 回到 **学习方案生成**，在课程名输入框里打 `我想自杀`，点生成 | （语气放慢、放低）"接下来这段，是**任何产品都不该回避**的。当一个学生输入这样一句话 ——" |
| 5-2 | 25s | 画面弹出**热线卡片**：两条热线 + `tel:` 拨号按钮 + 「先不着急做学习计划」 | "系统**不会再让他去做学习计划**。它给出两条**人工核验过**的心理援助热线，而且是可点击直接拨号的。" |
| 5-3 | 15s | **镜头怼近状态栏**，让 `duration_ms` 数字占满画面 | "请注意这个耗时 —— **毫秒级返回**。" |
| 5-4 | 15s | 打开 **日志 / Trace 抽屉**，指出 `"crisis": true` 那一行 | "日志里能看到：这次**一次模型调用都没有发生**。号码不是大模型写的，是我们**写死在代码里的常量**。" |

**这四句必须原样说（口径已被队长确认）**：
> ① "**0 次模型调用，毫秒级返回**" —— 不要说"四条链路都跑完了"
> ② 步骤条会显示 **4/4 全绿**，那是前端**强制置绿**的，**别解说成"链路都跑了"**
> ③ 号码"**由系统直接给出，不经过 AI 生成**"
> ④ 顺手拍一下：危机页面的 **导出按钮消失了**（已实测确认消失，两道保险：三栏区整体不渲染 + 导出条件依赖大纲非空）

**为什么这段最值钱**：别人会讲"我们有内容安全"，但你能证明**号码是常量、路径是短路、耗时是毫秒**。
这是可以用日志当场对质的。

## 六、已知坑与替代方案

| 坑 | 影响 | 处理 |
|---|---|---|
| **录音转写在 http 下用不了** | 浏览器安全上下文限制，`getUserMedia` 被拒 | **首选跳过这一幕**；一定要展示，就在那一页用「粘贴整理」兜底并说明"线上开启 HTTPS 后可直接录音" |
| 危机句会**覆盖**当前结果 | 三栏被热线卡片替换 | 危机镜头**放在最后**录；或录完先刷新页面 |
| 步骤条 4/4 全绿 | 视觉上是"全跑完了" | 解说按第四节的四句话，别自由发挥 |
| 问答命中不到知识库 | 会显示"来源：大模型" | 提问前先在知识库页搜一下确认材料里有该内容 |
| 视频里出现真实学生的数据 | 隐私问题 | 录之前确认历史/进度里**只有自己的测试数据**（匿名历史刚清理过，只留「机器学习」） |

## 七、备用话术（万一某个功能现场翻车）

- **导不出来** → "导出是本地生成的 Word，不依赖网络。"（然后切到已经导好的文件）
- **问答转圈太久** → "它在检索知识库并等模型生成，我们直接看已经准备好的这一段。"
- **思维导图空白** → "导图是学生自己编辑的，我这边先展示结构视图。"
- 任何页面报错 → **不要现场解释错误**，切走，事后补录这一镜
